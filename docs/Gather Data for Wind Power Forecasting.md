# Gather Data for Wind Power Forecasting

## SCADA 数据

| 特征               | 描述                                                    |
| ------------------ | ------------------------------------------------------- |
| 风速               | 在轮毂高度测量                                          |
| 风向               | 在轮毂高度测量                                          |
| 风功率输出（滞后） | 实际发电功率（单位：MW 或占装机容量的百分比             |
| 偏航角             | 未对准会降低功率；指示跟踪性能                          |
| 叶片螺距角         | 反映涡轮机控制状态（限电、限流）                        |
| 转子转速           | 与风能捕获动态相关                                      |
| 风力涡轮机状态     | 运行/故障/维护标志，确保功率损耗不是由于故障/维护造成的 |

## 气象站数据（测风塔数据、超声波风速仪数据）

| 功能 | 描述                                                       |
| ---- | ---------------------------------------------------------- |
| 温度 | 当地气温 (°C)，空气密度校正（功率输出 ∝ 密度 ∝ 压力/温度） |
| 压力 | 大气压力 (hPa)，影响空气密度和风的流动                     |
| 湿度 | 相对湿度 (%)，弱相关性，有时用于空气密度校正。             |

## 数值天气预报 (NWP) 数据

| 功能          | 描述                 |
| ------------- | -------------------- |
| 预测风速      | 多个高度和时间步长   |
| 预测风向      | 多个高度和时间步长   |
| 预测温度      | 地面和轮毂高度       |
| 预测气压/湿度 | 作为附加天气预报指标 |

## 时间特征

| 特征           | 描述             |
| -------------- | ---------------- |
| 一天中的小时   | 捕捉每日周期     |
| 一周中的某一天 | 用于运行模式     |
| 月份           | 季节性风廓线变化 |
| 季节           | 季节性风廓线变化 |
